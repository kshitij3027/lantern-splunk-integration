# Lantern → Splunk integration

A Python prototype that validates exported forensic findings, preserves the original evidence, maps useful fields to Splunk conventions, and imports eligible versions through HTTPS HTTP Event Collector (HEC).

Implementation is in progress. This repository uses synthetic examples; company-provided assessment files and live credentials are deliberately excluded. The final README will contain verified setup, commands, quality policies, and investigation searches.
